## ⬇️ 在 Lithe 中安装

需要 Lithe 0.6.1 或更新版本（目前插件市场只在 macOS 提供）。Lithe 已预置本仓库作为社区插件源，
打开 **设置 → 插件 → 插件市场** 即可浏览和安装；安装前会弹窗列出插件权限、要运行的程序和来源仓库。

如果之前移除了 Lithe Store，在 **设置 → 插件 → ⚙ → 管理插件仓库…** 中重新添加
`https://github.com/Lithe-IDEA/Lithe-store` 即可。
